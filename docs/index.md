# SleepLab Documentation

Welcome to the SleepLab documentation site. SleepLab is an open-source health data platform designed with local-first and privacy-focused principles.

## Key Features

- **Automated Data Ingestion:** Pipelines for processing binary and complex health telemetry.
- **Telemetry Streams:** Continuous SpO2 and Heart Rate data analysis.
- **Visualization:** Time-series dashboards and metrics visualization.
